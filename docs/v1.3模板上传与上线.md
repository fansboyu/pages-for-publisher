# v1.3.0 模板上传、备案与存储验证

后台新增管理员专属「模板管理」：ZIP上传 → 安全校验 → 固定版本/私有原包归档 → 网站绑定 → 官网资料编辑 → 安全草稿预览 → 显式发布。
目录导入仍保留用于运维；代理商不能上传模板、绑定模板/服务器、发起存储检测或读取其他站点。

## 存储

- 图片 `OSS_MEDIA_BUCKET`，长期HTTPS匿名读取，不公共写。
- 模板源ZIP：私有 `OSS_ARCHIVE_BUCKET/templates/<内容哈希>/source.zip`。
- 发布包：私有 `OSS_ARCHIVE_BUCKET/archives/sites/...`，Agent取得临时签名下载地址。
- 解压模板：持久化卷 `/data/templates/<内容哈希>/`；PostgreSQL保存元信息、对象key和校验报告。
- 本地驱动仅用于验证。修改.env后必须重新创建API和Worker，不能仅restart。
- OSS检测创建独立随机前缀对象，验证读写、图片HTTPS、私有匿名拒绝与签名下载，并只删除本次对象。
  RAM需两个Bucket指定前缀的PutObject/GetObject/DeleteObject；不需要给整个账号管理权限。
  检测失败只返回错误类型/状态，不返回Secret或带签名地址。

## 限制与安全

模板ZIP默认64MB、展开256MB、最多10000条目。TEMPLATE_MAX_COMPRESSED_MB / TEMPLATE_MAX_UNPACKED_MB / TEMPLATE_MAX_FILES独立配置。
上传原始application/zip，按流接收，不使用JSON/base64包装；只支持ZIP及单层外包目录。
拒绝越级/绝对/隐藏路径、软链接和特殊条目、重复大小写路径、加密包、程序文件及超限解压。
导入时执行协议检查和带测试文章的真实构建/资源检查，不执行模板脚本。
初始化defaults仅显示参考，不自动覆盖网站内容。

备案字段保存在sites.content JSONB；内容API白名单和号码/链接校验、表单、siteView、发布快照与构建器均接通。
standard-static-v1.1必须声明icp-fields；未知requiredCapabilities拒绝。
需该能力的网站，电话或备案号缺失会导致构建失败，旧版本不变。备案链接限制https://beian.miit.gov.cn/。
旧模板不强制新增备案占位符，便于渐进升级；运营应迁移旧模板以确保全站页脚正确。
文章生成路径冲突时拒绝构建，不覆盖固定页面；JSON-LD标题/摘要防script闭合。

预览有效30分钟、仅创建者可访问，受账号网站范围校验；CSP sandbox禁用脚本、表单、顶层跳转。
为加载同源资源允许same-origin，但绝不允许scripts。预览不写releases，不派发Agent。
过期目录在后续创建预览时按批清理。已发布后台预览也隔离脚本；正式客户Caddy网站保留交互。
动画/交互需在独立客户测试域名验收，安全预览不等于交互验收。

## 部署与回退

升级前保存pg_dump、platform-data卷、.env及Caddy/Compose配置；备份仅root可读，不进入Git。
003迁移仅新增模板元信息和预览表，不修改已有客户内容。旧版可忽略新增表/列，应用回退无需删除数据。
保存旧镜像和compose.deploy.yml，健康检查失败先恢复旧镜像；只有数据损坏才考虑停服务后恢复数据库备份。
不要覆盖.env，不重置数据库/Redis密码，不运行docker compose down -v。
