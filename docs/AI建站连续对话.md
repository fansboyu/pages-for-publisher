# AI建站连续对话（v1.3.9之后的本地增量）

当前未推送GitHub、未改标签、未部署生产。启用前执行迁移012；现有API/Worker继续承载，不新增容器或.env参数。

## 使用

进入AI智能建站，选择网站。首次生成选“整站”；后续可选择配色、首页主视觉、SEO或具体模块，输入本次修改要求。每次真实生成仍须确认报价，结果先保存草稿。选择范围之外的模型返回字段由程序丢弃，不直接覆盖。

对话面板显示用户指令、任务状态、实际成功版本与字段前后差异。失败/待核查任务不会显示为成功版本。手动编辑和撤销也记录实际结果。“撤销上一步”将上一版配置复制为新的草稿版本，不删除历史、不收费、不改变已应用官网或线上发布版本；仍需保存并发布才上线。连续点击撤销会撤销上一次操作，包括撤销操作本身。

## 上下文

按网站持久化消息，权限沿用siteFor。每个网站目前共用一个会话，多个员工在同一网站看到同一份记录，并受草稿版本冲突保护。

请求模型时读取最近40条消息，其中最近16条携带有限长度的内容和差异，较早成功结果压缩成最多2500字符的记录摘要。更早消息仍在数据库，但此版本不提供无限上下文或永久偏好记忆，也未新增LLM摘要调用。页面显示最近60条。当前草稿始终是真实状态，撤销后的旧指令不应覆盖新状态。

DeepSeek接口仍由服务端现有兼容接口调用：系统规则、企业资料、知识库、当前草稿、编辑目标、对话上下文和当前指令。返回完整结构化配置，服务端按目标范围合并；尚非任意HTML或自由代码修改。演示模式支持颜色、加深、标题等有限指令，不能代表真实模型理解任意对话的效果。
