# 数告星发布中心 v1.4.0：系统功能详细介绍

版本：v1.4.0｜文档日期：2026-11-07｜适用对象：企业负责人、直营员工、代理商、交付与运维人员。

本文件描述本版本源码提供的能力，不代表生产主控已经升级。GitHub发布与生产部署是两个独立动作；本次发布不会修改生产服务器或生产.env。

## 1. 产品定位

数告星发布中心是一套多客户企业网站运营与发布系统，将企业资料、官网制作、文章生成、静态网站构建、客户服务器部署、版本回滚、访问统计、金额账单与AI品牌查询集中管理。

典型用户包括统一维护客户网站的直营团队，以及管理自己客户和内容的代理商。客户网站部署在客户服务器；主控管理内容、任务与版本，客户Agent负责拉取发布包，客户侧Caddy负责网站访问与HTTPS。

| 备份与告警 | 数据库/平台文件备份、重复告警抑制 | 异地复制和恢复演练需要运维执行 |

## 4. 角色与数据归属

直营管理员admin可查看全平台客户、管理模板、服务器、代理商与资金。agency账号只访问所属代理商客户；同一代理商的员工共享代理商范围。员工页面权限和资金写入权限仍由后端检查，隐藏菜单不是数据隔离手段。

归属链路为：代理商 → 客户 → 网站 → 文章、发布版本、任务与统计。知识库按客户共享。GEO查询、建站任务和外发订单按网站校验；指定其他网站ID不能绕过归属检查。

## 5. 官网交付流程

```mermaid
flowchart LR
 A[创建客户与网站] --> B[补充资料和知识库]
 B --> C[导入模板或AI制作官网]
 C --> D[检查草稿并应用]
 D --> E[绑定客户服务器与域名]
 E --> F[发布冻结内容]
 F --> G[构建Worker生成发布包]
 G --> H[Agent拉取并部署]
 H --> I[客户Caddy提供访问]
 I --> J[访问统计与后续运营]
```

发布会保存内容和模板快照。部署失败时旧网站通常继续提供访问，后台显示失败任务供核查。新增站点和单站回滚应保持同一服务器其他网站路由不变。

## 6. AI建站与图文运营

AI建站保存结构化网站草稿和版本。每次对话保存用户指令、结果、版本与字段变化，模型接收受限历史和企业资料。可按整站或受支持模块范围修改；受保护范围由后端合并，避免要求改标题却修改其他模块。

生成草稿、手动保存、应用到官网内容、发布网站分别是不同操作。撤销仅生成一个恢复后的新草稿，不能代替正式发布版本回滚。

AI图文使用文字与图片两个供应商配置：文字形成标题、摘要、SEO与小节；图片按小节提示生成、下载、压缩和持久化后插入文章。现有流程无人工审核节点，生成文章后进入发布编排。文章持久化或模型失败会显示异常，不静默伪装成功。

## 7. 外部网站媒体发布

用户选择网站已有文章和最多10个渠道，查看媒体规则、参考价格、案例及报价。确认后创建批次与子订单，由外部Worker处理和查询状态。

渠道分类来自供应商get_field接口，行业/门户/地区等分别使用真实分类ID。当前供应商目录逐页读取；筛选与价格排序只作用于当前页，页面有范围说明，不宣称全库检索。渠道卡片的可用状态和价格由供应商数据决定。

一篇文章的外发快照不会随原文章编辑或删除改变。部分渠道成功时分别跟踪结果。超时或状态不明进入待核查，避免重复下单。生产真实刊发、供应商价格变动以及退款结算需要联合验收；本地模拟成功不证明真实刊发成功。

## 8. GEO品牌查询与AI数据中心

支持一个问题多个平台，按问题×平台计价。正式支持平台编号1、2、3、4、5、6、8；Kimi编号7暂不开放正式创建任务。管理员还能关闭其他单个平台。

界面包含数据报表、发起查询和查询记录。报表展示查询数、命中数、查询中任务、品牌词数、平台命中占比、查询/命中柱图及七天趋势。记录包含平台、状态、时间、截图/分享及关联账单。

正式闭环为：报价2分钟有效 → 确认金额 → 同事务预占和排队 → Worker提交并保存request_id → 周期查询 → 命中/未命中均正常扣款 → 供应商明确失败退款时释放预占 → 截图独立归档。

初始价格0.20元/问题/平台。例如1个问题×3个平台=0.60元。演示金额为0，不调用真实供应商。仓库默认GEO_QUERY_MODE=demo，价格启用开关默认关闭；当前操作者的本地环境配置不随Git发布。

截图使用现有公开图片存储：本地/objects/media地址，OSS为配置的公开图片域名。查询记录本身仍需登录并按客户范围读取。截图失败只重试归档，不重发付费任务。无截图明确展示空态。

## 9. 金额控制

余额以整数分保存，流水追加不可修改。预占金额不是立即扣款；可用金额=余额−预占。客户月预算覆盖现有计费订单，包括GEO与外发订单，不任意覆盖既有预算。

直营管理员可充值、配置单价、设置客户结算账户与月预算，并在核查后释放不确定订单或退款。供应商按算力收费属于平台上游成本，客户界面继续只使用金额。

## 10. 运行与交付组成

主控常驻容器：frontend、api、worker、postgres、redis。按需启用external-worker处理媒体与GEO；按需启用provisioner处理SSH接入。migrate为一次性迁移容器。

客户侧独立部署Agent和Caddy，不属于主控Compose。客户网站可在主控短时离线时继续访问，但新发布任务需要主控恢复。

持久数据包括postgres-data、platform-data，以及OSS中的图片/私有归档。Redis包含构建队列状态与缓存，也应结合数据库outbox和恢复流程管理。不要把Redis卷可重建理解成所有业务数据可丢弃。

## 11. 验收与未完成事项
