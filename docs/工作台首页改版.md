# 工作台首页改版（本地未发布）

在v1.3.9基础上新增工作台首页，保留已有网站管理页面。当前未推送GitHub、未改版本标签、未部署生产。

## 界面

柔光AI横幅、四个功能插画入口、统一导航SVG图标、企业接入流程、最近发布、待办异常；列表及业务表单保留原有简洁布局。窄屏支持两列卡片、单列内容和导航展开按钮。

入口为工作台，图文、建站、知识库和发布按钮进入原业务页面。最近发布和知识库待办选择对应网站。无需新增.env、迁移或容器。

## 数据口径

- 已上线网站：账号可见网站中具有active_release的数量，不是公网健康探测。
- 本月AI图文：现存文章中ai_generated_at位于北京时间当月的条目；不作为不可变历史产出报表。
- 近7天PV：按北京时间自然日汇总现有统计表。
- 本月消费：本月计费流水扣款减退款；不含预占，可能因跨月退款出现负数。
- 可用金额：可见账户余额减预占金额的合计。管理员查看合计，不代表其个人钱包。
- 异常：当前state返回的近期构建/部署记录，按网站取最近一项；不是完整告警中心。
- 知识库待办：可见客户中尚无知识条目的客户数量，不检查资料真实性或完整度。

所有数据均遵守现有代理商归属；加载失败展示错误与重试，不伪装为0。
