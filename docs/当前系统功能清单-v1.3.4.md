# 数告星发布中心功能清单

**版本：v1.3.4**
**用途：** 说明当前代码已经具备的功能、运行所需配置，以及尚未实现的边界。

## 一、系统定位

数告星发布中心用于统一管理企业官网内容，并将静态网站安全地构建、发布到客户服务器。平台由管理控制台、API、PostgreSQL、Redis/BullMQ 构建队列、Worker 和客户侧 Agent/Caddy 组成。客户网站发布后以静态文件运行；客户服务器不需要连接主控数据库或 Redis。

```text
平台管理员 / 代理商
        │ 管理客户、网站、内容和发布
        ▼
发布中心控制台 → API → PostgreSQL
                         │
                    Redis / Worker
                         │ 构建不可变网站包
                         ▼
                    主控归档存储
                         │ Agent 领取并校验任务
                         ▼
                 客户服务器 Agent + Caddy
                         │
                  企业官网 / 文章页面
```

## 二、已实现功能

| 模块 | 当前已实现的功能 | 使用说明 |
|---|---|---|
| 平台账号与代理商 | 平台管理员登录、创建代理商及账号；按代理商归属隔离网站和业务数据 | 当前有管理员和代理商角色；客户独立登录账号尚未实现 |
| 企业与网站 | 企业归属、创建和管理多个网站；每个站点可配置域名、站点内容、模板、服务器 | 同一家企业可管理多个独立站点 |
| 地区站运营 | 从现有站点创建地区站，填写地区、独立域名和地区重点词；沿用同一企业和模板，复制首页初始内容 | 每个地区站是独立站点，文章、SEO、统计、版本彼此分开；企业知识库共用。新地区站不会复制文章历史或服务器绑定 |
| 官网内容编辑 | 编辑首页标题、介绍、电话、备案信息等站点资料；保存草稿并单独发布 | 修改草稿不会直接覆盖当前线上版本 |
| 文章管理 | 创建、编辑、删除文章；支持富文本和图片；支持草稿与已发布状态及 SEO 标题、摘要、关键词 | 文章修改后需发布网站使其上线 |
| AI 图文创作 | DeepSeek 生成文章；阿里云百炼生成封面和正文配图；图片保存到配置的存储并插入正文合适段落 | 默认 1 张封面和 2 张正文图，可选择 3 张正文图。生成成功后自动提交发布，无人工审核节点。未配置真实模型时使用明确标识的演示模式 |
| 企业知识库与行业词库 | 按企业保存分类、资料标题、已核实内容和行业词；同一企业的地区站共享知识库 | AI 生成时会读取这些资料。真实 AI 配置下，相关资料会发送给对应文本模型服务 |
| 模板管理 | 管理员上传 ZIP 模板，进行安全解压、协议校验和构建检查；模板版本可绑定至网站 | 支持安全草稿预览；预览不会发布到线上，也不会执行模板脚本 |
| GEO 内容接口 | 每个网站有独立 API Key；支持外部文章创建或更新，按 `external_id` 幂等处理 | 可保存草稿或提交发布任务；需对接方自行安全保存 API Key |
| 网站构建与发布 | 保存不可变内容快照，由独立 Worker 构建完整静态网站包，再排队发送客户 Agent | 同站点构建按版本顺序执行；任务失败可查看原因并重试 |
| Agent 与 Caddy 部署 | 客户服务器 Agent 主动向控制端领取任务，校验发布包后切换站点目录；一台服务器可托管多个站点 | Agent 通过服务器独立 Token 鉴权；可与客户现有业务共存，但需按部署规范配置专用 Caddy 和管理接口 |
| 版本回滚 | 保存网站发布历史，可将客户网站切换回可用的历史发布版本 | 回滚网站版本不会覆盖当前编辑草稿；主控系统版本回退是另一项运维操作 |
| 图片与归档存储 | 图片可使用本地或 OSS 存储；发布包、快照及模板 ZIP 可独立使用归档存储配置 | OSS 需要正确配置 RAM 权限、Bucket、地域和图片 HTTPS 访问域名；本地测试不代表 OSS 公网验证成功 |
| 访问统计 | 统计 PV、期间去重访客估算、每日趋势、热门页面、来源、设备及访问域名 | 新网站发布后自动带统计脚本。额外域名保存后需重新发布；访客标识为估算值，不保存原始 IP |
| 告警 | Worker 可通过通用 JSON Webhook 提醒构建失败、部署失败和绑定站点的 Agent 离线 | 需配置 `ALERT_WEBHOOK_URL`；钉钉/企业微信需由接收端将通用 JSON 转换为对应格式 |
| 备份 | `npm run backup` 生成 PostgreSQL custom dump、平台 `/data` 文件归档、清单和 SHA-256 校验文件，并按保留份数清理旧包 | 需在可访问生产 Docker Compose 的部署目录手动执行；可由 cron 或 Windows 任务计划程序调度 |
| 操作与权限保护 | 后台 Session、GEO 站点 API Key、Agent 服务器 Token 分别鉴权；重要操作写入审计日志；数据库使用顺序迁移 | 代理商不能读取其他代理商的数据或执行平台级服务器管理 |

## 三、发布与地区运营流程

```text
创建企业和网站
      ↓
设置域名、模板、首页资料和服务器
      ↓
补充企业知识库与行业词
      ↓
（可选）为各地区创建独立地区站和域名
      ↓
编辑内容，或用 AI 生成图文文章
      ↓
构建静态版本并自动提交部署
      ↓
检查构建/部署结果、线上访问和访问统计
      ↓
需要时回滚至历史版本
```

## 四、需要人工或部署环境提供的配置

| 配置 | 何时需要 | 谁通常负责 |
|---|---|---|
| 客户企业资料、网站内容、可公开事实和行业词 | 使用 AI 创作、运营官网时 | 企业运营人员 / 代理商 |
| 地区站名称、地区、地区重点词、地区域名 | 运营多个地区站时 | 企业运营人员 / 代理商 |
| 域名 DNS、客户服务器公网连通、HTTPS 证书 | 网站对外提供访问时 | 企业 IT / 运维 |
| 客户服务器注册、Agent Token、部署目录及 Caddy 配置 | 发布到客户服务器时 | 平台管理员 / 客户运维 |
| DeepSeek 文本 API 和阿里云百炼图片 API 凭据 | 使用真实 AI 文章和图片生成时 | 平台运维 |
| OSS Bucket、地域、RAM 凭据和图片访问域名 | 使用 OSS 保存图片或归档时 | 平台运维 / 云资源管理员 |
| `ALERT_WEBHOOK_URL` 和告警接收端 | 需要外部故障提醒时 | 平台运维 |
| 备份调度、异地保存位置和恢复演练 | 生产数据保护时 | 平台运维 |

## 五、当前功能边界

- 客户本身没有独立登录角色；目前由管理员或代理商代为管理客户资料和网站。
- 地区差异通过“同一客户下多个独立站点”实现；一个站点按访问域名自动切换不同地区内容的能力尚未实现。
- 知识库为人工录入的结构化资料和行业词，不包含文件自动解析、向量检索或自动从企业网站抓取。
- 自动备份需要外部调度器；命令不自动上传 OSS，不包含 `.env`，也没有后台一键恢复功能。生产备份应复制到独立故障域并验证恢复。
- 告警需要配置接收 Webhook；系统提供通用 JSON 格式，不是钉钉或企业微信的原生机器人适配器。
- 计费、套餐配额、客户自助门户、自动排期发布、社交媒体分发、企业级跨地区汇总报表、自动容灾和多主控高可用尚未实现。
- 公网 DNS、客户 HTTPS、真实模型服务、真实 OSS 及生产告警是否可用，取决于相应账号凭据和部署环境；自动化本地测试不等同于生产验收。
