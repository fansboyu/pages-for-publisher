# 人民币计费使用与验收

本模块为 v1.3.5 标签之后的本地增量，原标签保持不动，尚未上传 GitHub 或部署生产。

## 账户和权限

- 全部使用人民币金额，数据库按整数分保存，不引入积分。
- 默认代理商统一结算；直营管理员可将指定客户切为独立结算。切换不转移原余额，有待结算任务时禁止切换。客户本身没有新增登录角色。
- 直营可登记已确认的线下充值、配置价格和客户月预算、核查待对账任务，以及将已扣款任务全额退回原余额。代理商只能查看所属账户和流水。
- 充值与退款仅是平台内部账目登记，不连接支付平台，也不向银行卡或支付账户转账。

## 使用步骤

1. 直营登录后打开“余额与账单”，配置文章单价、每张图片单价，再启用真实图文价格。初始未启用，不擅自设定客户售价。
2. 必要时先为客户选择独立结算和月预算，再为相应账户登记人民币充值及收款备注。
3. 在 AI 图文页面选择参数并提交，弹出本次人民币报价。真实文字与图片模型须同时配置；纯演示模式明确标示免费，并记录零元流水。
4. 服务端重新计算价格并检查报价版本、余额、客户月预算和账户并发数，然后冻结费用。
5. 图文和文章成功持久化后扣款，再提交网站发布。计费对象为生成服务：网站发布失败不重新生成或重复收费，可在文章页面手动重新发布。
6. 在账单页面查看余额、冻结、可用余额、任务状态及最近100条流水。数据库保留完整记录。

## 金额规则

- 图文金额 = 每篇文章单价 + 每张图片单价 ×（1张封面 + 正文图片数量）。视频价格仅为未来参考字段，不能提交视频任务或产生视频收费。
- 报价在任务提交时锁定，价格调整不修改旧任务金额。服务端不信任客户端传入价格。
- 金额最多两位小数，单次金额和账户余额上限人民币100万元。初版每个结算账户最多同时存在两项处理中/待对账任务。
- 客户月预算使用北京时间自然月，包含已扣款、冻结及待对账金额；解冻/退款释放预算，纯免费演示不占金额预算。
- 请求编号在同站点范围去重。同编号同参数成功后返回原结果；参数不一致拒绝；处理中任务不能重复调用供应商。
- 充值请求亦有幂等编号；前端在当前浏览器会话保留未确认的请求，减少断网重试重复充值的风险。

## 失败与对账

- 明确生成或持久化失败时整单释放冻结金额；已产生的上游成本由平台承担。本版不按部分成功图片结算，也不支持单张补图计费。
- 超时、网络断开等不确定错误进入待对账，不立即释放或再次调用供应商。进程崩溃留下的冻结订单不会自动扣款或自动退款。
- 直营可在核查供应商、数据库和任务结果后填写依据释放待对账订单；仍处于冻结的订单至少经过一小时才允许人工处理。
- 已交付的收费任务可由直营填写原因全额退回原账户余额，不支持重复退款。退款后文章依然存在，原请求不能再次触发生成。
- 文章入库和扣款在同一数据库事务中提交；发布提交与生成结算分开，已生成但发布提交失败的内容可以单独发布。
- 资金流水只追加，应用不修改或删除历史流水，数据库触发器拒绝 UPDATE/DELETE；数据库管理员仍有最高权限，生产应另做备份和审计。

## 当前边界

当前沿用同步 AI 请求，并以数据库订单保护超时、重试和重复提交。尚未引入 AI Worker、进度订阅和后台自动对账；浏览器断开后应先在账单核查，不另开相同生成任务。

没有在线支付、自动开票、部分退款、按视频时长/分辨率收费或实际供应商成本自动采集。价格快照保留配置的模型名称，供应商实际成本需另行核算，不把用户售价当成上游成本。真实模型/OSS 联调仍取决于配置与账号。

## 开发入口与验证

- 迁移：`pilot/migrations/008_billing.sql`。
- 账户、报价、资金事务：`pilot/billing.mjs`。
- 管理 API：`GET/POST /api/billing`，报价 `POST /api/sites/:id/ai-quote`，生成仍走 `POST /api/sites/:id/ai-articles`。
- 前端：`public/billing-ui.js` 与现有 AI 表单。代理商权限继续由后端执行。
- 验证：`npm run test:billing`、`npm test`、`npm run test:permissions`、`npm run test:ai`、`npm run test:frontend`。

验证使用独立本地 PostgreSQL 数据库检查金额、并发、预算、幂等、退款和代理商隔离；主发布测试使用真实本地 Redis/Worker/Caddy，模型为演示或 mock。未进行真实资金收付。

标准前端全量 Docker 构建曾因本机镜像源连接超时受阻；使用已缓存前端镜像覆盖新静态文件和原代理配置完成本地容器验证。生产全量构建应在镜像源可用环境重新执行。
