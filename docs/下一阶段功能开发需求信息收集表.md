## 五、容器和任务协作的目标

建议目标容器：

```text
frontend → api → PostgreSQL
                  ├─ Redis/BullMQ → build-worker
                  ├─ Redis/BullMQ → ai-worker
                  ├─ Redis/BullMQ → video-worker（视频功能上线时）
                  └─ 接入任务 → isolated provisioner

build/AI/video workers → OSS
provisioner ──短期 SSH──► 客户服务器安装 Site Agent
客户 Site Agent ──主动轮询──► API 领取后续部署任务
```

| 需要确认 | 你的选择/补充 | 建议默认值 |
|---|---|---|
| AI 文章是否改为异步任务并显示进度 | 是 / 否 | 是，统一任务编号、状态、错误和重试 |
| 视频是否独立队列和 Worker | 是 / 否 | 是，避免长视频任务阻塞网站构建 |
| 服务器接入是否独立 Provisioner 容器 | 是 / 否 | 是；不让普通 API 或构建 Worker 持有 SSH 凭据 |
| 备份运行方式 | 定时一次性任务 / 常驻容器 | 定时一次性任务，备份写往独立故障域 |
| 任务状态保留时间 |  | 保留足够排障与审计周期，媒体文件按另一套策略管理 |
