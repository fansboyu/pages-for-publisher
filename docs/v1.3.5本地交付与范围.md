# v1.3.5 本地交付范围

本版本按低开发量优先交付，沿用两类角色：直营账号对应现有 admin，代理商对应 agency。

## 已实现

- `/api/state` 返回页面权限，前端据此过滤菜单并阻止进入未授权页面。
- 代理商不可见服务器、模板管理和 GEO 密钥页面；站点状态不向代理商返回 GEO Key 或服务器编号。原有 API 归属与管理员校验继续执行。
- 新增员工账号页面。直营管理员可管理全部代理商员工；代理商只能创建及启停本代理商账号。员工继承所属代理商同等业务权限及员工管理权限，不增加第三种角色或复杂权限编辑器。
- 创建账号强制服务端确定归属，不接受代理商伪造其他代理商归属。停用、启用均撤销原会话；禁止更改自己的状态，禁止员工管理接口操作直营管理员。
- 新增账号状态迁移 007；创建和启停操作记录至数据库审计日志。不返回密码哈希。
- AI 视频入口及只读 `/api/video/capabilities` 明确标为未开放，便于后续接入。无生成任务、无模拟成片和模型费用。
- 没有配置网站的代理商仍可管理员工和进入视频规划页，其余站点功能显示空态。

## 后续范围

视频供应商、视频 OSS、配音/字幕、AI 异步 Worker、SSH 自动接入及 NPM 适配留待后续。现有 AI 图文自动发布行为保持现状。本版本未实现密码重置、员工等级或逐人细分权限。

## 验证及发布

执行 `npm test`、`npm run test:ai`、`npm run test:frontend` 和 `node tests/permissions-ui.mjs`。主测试使用独立测试数据库、真实本地 PostgreSQL、Redis、Worker 和 Caddy，覆盖归属隔离、账号停用撤销会话、发布和回滚。图文供应商测试使用 mock，不代表真实视频或 SSH 联调。

数据库升级先执行迁移 007，再启动新版 API。回退旧 API 会失去账号停用保护，应保留新版直到具备匹配的回退方案。

仅本地提交和创建 v1.3.5 标签，不执行 push、GitHub Release 或生产部署。等待用户提供后续验证信息并授权上传。
