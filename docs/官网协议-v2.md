# 官网协议 v2（本地开发增量）

协议名称 `standard-static-v2`，适用于新上传模板。旧模板不声明协议、v1、v1.1继续按原规则发布，不自动迁移。AI建站配置由服务端规范化为version 2，文章路由仍由绑定模板提供。

## 新模板配置

在原 publisher.config.json 的首页、列表、详情、卡片、资源目录、文章输出路径等字段之外增加：

```json
{
  "protocol": "standard-static-v2",
  "schemaVersion": 2,
  "latestArticlesLimit": 6,
  "capabilities": ["article-entry", "latest-articles", "article-list", "article-detail", "shared-theme", "analytics"]
}
```

首页、文章列表、详情模板必须包含 `{{company_name}}`、`{{theme_css}}`、`{{site_navigation}}`、`{{site_footer}}`。后三者由系统生成，不能把普通文字塞入这些位置。theme_css放head，导航、页脚放body。模板自身的CSS仍应使用统一主题变量，不能用固定色覆盖它。

首页文章容器必须有 `data-publisher-latest`，容器内部放原配置的文章卡片占位符。详情正文容器必须有 `data-publisher-article`，内部放 `{{content_html}}`。首页与列表仍须保留原文章卡片占位符。v1.1的电话和备案必填策略保持不变；v2可继续通过requiredCapabilities声明必填能力。

## AI建站

- 服务端向模型提供固定协议规则，并在模型返回后重新规范化；提示词不能删除系统文章模块。
- 官网、文章列表和详情由同一个渲染器输出，统一主题、导航、企业名称和页脚；文章正文仍使用原安全过滤。
- 首页默认最近6篇文章，新文章随下次构建更新，无需重新调用模型。没有文章时展示空状态。
- 企业名称、联系电话、备案来自网站资料；路径、统计身份由系统管理。
- 视频和产品能力目前只在协议中保留默认关闭的声明，没有新增数据库字段或真实视频展示功能。Logo、地址、独立产品数据绑定尚待对应功能开发，不能视为已经实现。

## 最终检查

v2模板及AI建站最终产物检查：首页/列表/详情存在、统一导航页脚、首页文章区、详情正文区域、无残留占位符、应注入的统计标识。原有本地资源/页面链接校验、sitemap和robots生成继续执行。预览明确关闭统计时不要求统计脚本。失败不切换线上版本。

本次不改变日期字段语义：文章日期暂沿用原更新时间；分类默认名称调整为“文章资讯”，不新增分类管理。

## 本地验证

`node tests/website-protocol.mjs`：旧模板、新协议模板、无效模板拒绝、AI官网与文章统一主题、文章更新进入首页、空状态及最终检查。

`npm run test:website`：建站权限、任务、草稿、计费模拟和发布快照。

`npm test`：主发布、部署、回滚与多网站闭环。

协议本身不新增迁移和容器；AI建站需执行迁移011。纳入v1.3.9，生产部署另行执行。
