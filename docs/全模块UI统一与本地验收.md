# 全模块UI统一（v1.5.1）

按已确认的20模块草图实现真实前端页面。工作台继续使用现有界面，其余模块采用统一主题横幅、原有立体插画、青绿主操作、浅色内容区和统一状态样式。没有引入草图中的示例客户、模拟金额或模拟任务进度。

## 覆盖页面

网站管理、发布与版本、AI智能建站、AI图文、文章、视频规划、企业知识库、素材、官网编辑、外部媒体、AI数据中心、访问统计、余额与账单、客户与代理商、员工、模板、服务器与部署、服务器自动接入、GEO内容接入接口。连同原工作台共20个模块。

- 网站：卡片展示客户、地区和真实域名，次要操作继续收在“更多”。快捷绑定区移到列表下方。
- 编辑：保留原表单的ID/name和原提交处理器；建站保留独立草稿、对话与真实预览。官网文本预览随输入更新，明确标注未保存。
- AI图文：展示queued/running/succeeded/failed/review，不推测文字、图片的子阶段完成率，也不虚构进度百分比。报价确认和后台生成流程保留。
- 知识库与账号：资料/账号列表在左，原新增表单在右；窄屏顺序堆叠。
- 文章、账号与版本列表：按当前已加载且有权限的记录搜索、筛选，不宣称全库搜索。
- 外部媒体：常用筛选保留，高级字段折叠但不删除。保留供应商原分页、渠道限制、快照、金额确认和订单逻辑。
- 金额：汇总当前账号可见账户的实际余额、冻结和可用金额。账户概览、任务账单、资金流水与管理员配置分页签，所有原财务确认和提交处理保留。
- 服务器：服务器与绑定、部署任务、构建队列、模板导入与绑定分页签；注册IP、Agent状态、指纹预检和安装确认沿用原逻辑。
- 长记录：金额与服务器列表按当前已加载记录每10条本地分页，不替代后端记录范围。
- 视频：只显示规划和未开放状态，无生成请求入口。

## 代码入口

`public/module-ui.js`在页面HTML创建后、原事件绑定前增强布局，移动而不克隆已有表单节点。`public/module-ui.css`在现有样式之后加载。`public/app.js`调用展示层并转发真实AI任务状态。`public/index.html`引入资源。

`pilot/server.mjs`仅增加两个静态文件路径映射，业务API、数据库结构、计费、部署、权限和Worker边界不变。本次发布版本为v1.5.1，保留既有标签。GitHub发布不自动更新生产服务器。

## 本地运行

常规完整启动：`npm run dev`。运行中的旧API不会自动补齐新静态路径，需重启API。新样式与脚本必须和index.html同步部署到独立前端容器。

本次预览地址：http://127.0.0.1:4424/ 。演示账号见仓库AGENTS.md，只用于本地。外部媒体为mock，GEO为demo，未配置真实文字/图片凭据时图文为demo，不代表上游真实服务验收。

## 验证

- `npm run test:module-ui`：新隔离数据库、本地API、AI Worker与浏览器。覆盖20模块真实加载、桌面与移动端、搜索筛选、表单保存、页签、代理商权限、免费图文报价与后台结果。
- 该专项需要开发环境提供Playwright。可通过`PLAYWRIGHT_MODULE_PATH`指定已有`playwright/index.mjs`的绝对路径，不需要改动应用依赖或生产镜像。
- `npm run test:permissions`、`npm run test:frontend`：权限及前端静态资源/接口透传。
- `npm run test:pilot`：主发布、构建、回滚和Agent/Caddy闭环。

浏览器截图不得保存GEO内容接入页面的真实站点凭据。当前浏览器回归主动跳过该页截图，但仍验证页面布局。
