# v1.3.9 功能与升级说明

发布日期：2026-11-05。本版本发布源码，不自动更新生产服务器。

## 新增能力

- AI智能建站工作台：商务蓝、亲和绿、简约黑，结合客户知识库生成结构化页面配置。
- 对话修改、可选一张首页配图、模块调整、SEO编辑、桌面/手机预览和历史草稿。
- 草稿应用后进入原有发布、Agent部署、访问统计和回滚流程。
- 官网协议standard-static-v2：首页最新文章、统一主题列表/详情、最终产物检查，兼容旧模板。
- 现有Worker处理持久化任务；生成任务与费用预占同事务，完成结果与结算同事务；中断/超时进入待核查，不自动重复调用供应商。

## 部署注意

1. 备份PostgreSQL、platform-data、原.env、Compose文件和旧镜像。数据库使用逻辑dump，不能把运行中的数据库目录直接复制当成一致备份。
2. 保留原.env，核对已有模型配置；执行迁移011，同时更新API、Worker和前端。
3. 不必更新客户Agent，不新增容器。升级主控不会自动转换现有网站；AI草稿应用并发布后才改变页面。
4. 用测试网站验收真实文字模型、百炼图片和OSS。自动化使用演示与模拟服务，不等同真实供应商验收。
5. 建站文字暂沿用一次文章单价，图片按0/1张收费；视频和产品扩展仍默认关闭。
